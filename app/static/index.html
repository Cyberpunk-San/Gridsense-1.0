SYSTEM ARCHITECTURE

From telemetry to a safer microgrid

GridSense is an end-to-end demand forecasting and power-routing application for a weather-aware microgrid.

01Ingest

CSV or manual weather telemetry is validated and normalized into hourly feature rows.

→
02Forecast

QuickML or the local fallback predicts electrical demand for every forecast hour.

→
03Decide

Controller rules select Main Grid or Renewable Storage and raise critical alerts.

→
04Explain

Charts, route contributions, signals, logs, and the evidence table make each result auditable.

Why this matters: prediction alone does not protect a grid. GridSense connects the forecast to an explicit dispatch decision, battery reserve simulation, and an operator-readable explanation.
